# Proyek Praktikum Laravel - [Fadli Rahardiarsya]

Proyek praktikum mata kuliah Pemrograman Web berbasis framework Laravel 12. Aplikasi ini mengelola data mata kuliah dan dosen pengampu menggunakan arsitektur MVC, Eloquent ORM, serta database Seeder & Factory.

## Teknologi yang Digunakan
- PHP 8.2.12
- Laravel 12
- MySQL / MariaDB
